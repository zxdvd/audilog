# Changelog

## 0.1.0 — 2026-09-23

- Local microphone and system-audio capture behind the AudioCapture boundary.
- Streaming mono 16 kHz PCM16 WAV output with resampling, dropped-frame reporting, and session recovery.
- Embedded Whisper with macOS Metal / CPU, timestamp merging, JSON and Markdown output.
- Model downloads with pinned SHA-256, model selection, doctor and common audio-file import.
- Four-platform CI, real CPU inference smoke test, tagged binary releases and checksums.
